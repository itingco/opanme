PATCH CYCLE GERAI + AUDITOR (berdasarkan main itingco/opanme pada 19 Nov 2026)

PENTING: Ini adalah installer patch berbasis source asli, BUKAN ZIP file jadi yang langsung ditimpa.
Repo dapat dibaca tetapi pengunduhan seluruh source langsung ke container dan penulisan branch GitHub tidak tersedia.

1. Backup project Laravel dan DATABASE lebih dulu.
2. Ekstrak ZIP installer ke folder terpisah, bukan ke project.
3. Pada PC Windows dengan Python 3 jalankan dari Command Prompt:
   python APPLY_PATCH.py "C:\xampp82\htdocs\opanme"
   GANTI lokasi di dalam tanda petik sesuai folder project Laravel lokal yang benar.
4. Installer mengedit source Laravel lokal dan menghasilkan CHANGED_FILES_ONLY.zip
   dalam folder installer. ZIP ini memuat HANYA file yang diubah, sesuai struktur folder Laravel.
5. Salinan file sebelum patch ada di folder BACKUP_ORIGINAL untuk rollback.
6. Di root Laravel jalankan:
   php artisan optimize:clear
   php artisan route:list --path=cycle-audit
   php artisan route:list --path=gerai-admin
7. Login sebagai Admin, buat user role CYCLE_AUDITOR untuk akses audit baca-saja.
8. Uji cycle GERAI: scan UOM 1 dan UOM besar, qty 1 dan ubah, lihat konversi, tutup.
9. Uji pembatalan: Admin Gerai pemilik dapat membatalkan OPEN/CLOSED, akun lain harus 403.
10. Uji audit: user Auditor melihat hanya CLOSED / FINALIZED dan tidak punya endpoint override.

Tidak perlu migrate untuk patch ini. Status batal = BATAL; scan history tidak dihapus.
PENTING: tidak ada pengujian runtime pada ERP/DB aplikasi Anda dari sini.

CATATAN: Penerapan ditargetkan untuk revisi repo yang diperiksa. Jika terjadi 'Anchor tidak ditemukan',
berarti source lokal berbeda; rollback BACKUP_ORIGINAL dan jangan lanjut sebelum disesuaikan.
